Data Analytics Case Study

Canada COVID-19 Health Data Dashboard

Interactive Dash application tracking national and regional COVID-19 trends

PythonPandasPlotlyDash

Objective

Understanding how COVID-19 outcomes varied across Canadian regions, age groups, and gender required cleaning a large Statistics Canada dataset and making it explorable for non-technical users.

What I Did

  • Cleaned and deduplicated a Statistics Canada COVID-19 dataset using Python and Pandas
  • Built an interactive Dash web application with a year filter and linked Plotly charts
  • Delivered views for reported cases by region, nationwide year-over-year trend, age group, and outcome

Achievements

Delivered a fully interactive analytics application, letting stakeholders filter by year and explore COVID-19 trends across Canadian regions without needing to touch the underlying data.
